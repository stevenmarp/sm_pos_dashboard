POS Live Dashboard

One screen for the owner: what every point of sale is doing right now. Revenue, orders, top products and payment mix for the day, updated live the moment a cashier validates a payment. No refresh button, no report to run.
Key Features

Live Over The Bus

Every paid order pushes an update to the dashboard instantly. No polling, no manual refresh.

All POS On One Screen

Revenue and order count per point of sale, side by side. Perfect for multi-branch owners.

Today At A Glance

Revenue, orders, average ticket, open sessions, hourly chart, top products and payment methods.

How To Use

  • Install the module, nothing to configure
  • Open Point of Sale - Live Dashboard (POS manager access required)
  • Leave it open on the office screen: it updates by itself as sales happen
